# 성동구 상권 모니터링

성동구 17개 행정동과 250m 격자의 상권 등급(활성·쇠퇴·위험)을 분기별로 확인하고, 정책 적용 범위와 검토 기록을 함께 관리하는 연구 결과 공개 웹앱입니다. 성동구 공식 행정서비스가 아닙니다.

- 공개 주소: https://seongsu-observatory.vercel.app
- 연구 결과 공개: 2026-11-03
- 배포 방식: Vercel 무료(Hobby) 정적 배포. 외부 패키지, 서버 함수, 데이터베이스, API 키를 쓰지 않습니다.

## 등급 산출 기준

기준점은 모두 서울 값입니다(2026-11-07 개정, 연구 프로토콜 48·49; 2026-11-08 행정동 개·폐업·매출 계산 보완, 프로토콜 50). 서울 행정동 중앙값은 서울 열린데이터광장 상권 자료(425개 동), 임대료 기준점은 한국부동산원 서울 소규모 상가 임대가격지수, 격자 개·폐업·영업기간 기준점은 서울 일반·휴게음식점 인허가입니다.

| 등급 | 자료 | 위험 | 쇠퇴 |
|---|---|---|---|
| 임대료·매출 | 서울신용보증재단 1층 환산임대료, 외식업 점포당 매출(외식 매출 ÷ 점포 자료의 외식 점포 수, 서울 기준점과 같은 계산) | 임대료 상승률 > 서울 임대가격지수 상승률, 임대료–매출 격차 > 서울 | 임대료 상승률 ≤ 서울, 매출 증가율 < 서울 중앙값 |
| 개·폐업 | 서울신용보증재단 개업·폐업 점포 수 | 개업률·폐업률 모두 서울 중앙값보다 높을 사후확률 > 0.8 | 순폐업률(폐업률 − 개업률)이 서울 중앙값보다 높을 사후확률 > 0.8 |
| 영업기간 | 서울신용보증재단 영업·폐업 점포 평균 영업기간 | 폐업 점포 ≥ 서울 평균, 영업 중 점포 < 서울 평균 | 영업 중 점포 ≥ 서울 평균 |
| 업종 변화 | 서울신용보증재단 업종별 점포 수 | 외식업 비중 증가폭 > 서울, 생활밀착 점포 증감률 < 서울 | 전체 점포 증감률 < 서울 |
| 행정동 종합 | 위 4개 | 위험 3개 이상 | 쇠퇴 2개 이상 |
| 250m 격자 임대료·카드매출 | 카드 외식 매출(분기 30건 이상·3개월), 소속 행정동 임대료 | 행정동 임대료·매출과 같은 규칙 | 같은 규칙 |
| 250m 격자 종합 | 위 격자 등급, 외식업 인허가 개·폐업·영업기간, 전 업종 카드 업종 변화 | 위험 3개 이상 | 쇠퇴 2개 이상 |

- 행정동 개·폐업은 감마-포아송 경험적 베이즈로 추정합니다. 사전분포는 같은 분기 서울 행정동 중앙값과 서울 425개 동의 Marshall 적률 분산입니다. 어느 쪽으로도 0.8을 넘지 않으면 '근거 부족'으로 표시합니다.
- 격자 개·폐업과 영업기간은 경험적 베이즈로 추정하고(Clayton·Kaldor 1987, Marshall 1991), 서울보다 높거나 낮을 사후확률이 0.8을 넘을 때만 위험·쇠퇴로 봅니다(Richardson 외 2004). 어느 쪽으로도 0.8을 넘지 않아 활성이 된 격자는 '활성(근거 부족)'으로 따로 표시합니다.
- 쇠퇴 2개 이상은 선행연구 근거가 없어 유지한 값입니다.
- 2026년 2분기 사전 예측 4종(2026-11-03 발행)은 발행 당시 정의로 채점합니다. 브라우저가 두 정의를 모두 계산합니다.

**계산 방식**

- 등급 계산은 브라우저의 `src/grades.js`가 합니다. 기본 자료는 `data/grades/base.json`(집계값)입니다.
- 다음 분기 종합 등급은 다항 로지스틱 회귀(표준화, L2, C=1)로 예측합니다. 분기 자료가 새로 등록되면 브라우저에서 다시 학습합니다.

**분기 자료 등록**

- 서울신용보증재단 행정동 분기 원자료 4종, 카드 격자 CSV, 외식업 인허가 파일을 올리면 파일 종류와 분기를 자동으로 인식합니다.
- 서울 기준점을 새 분기로 갱신하려면 신보 점포·매출 파일과 일반·휴게음식점 인허가 파일을 서울 전체로 올리고, 부동산원 지수 값을 입력란에 등록합니다.
- 인허가 좌표(EPSG:5174)는 브라우저에서 WGS84로 바꿔 격자에 배정합니다. PROJ 변환 결과와 0.5m 이내로 일치합니다.
- 등록 자료는 그 브라우저에만 저장됩니다. 다른 PC나 담당자와는 JSON 내보내기·불러오기로 옮깁니다.

**사전 예측 검증**

- `data/grades/issued_2026Q2.json`에는 2026년 2분기 자료가 공개되기 전에 작성한 예측 4종이 들어 있습니다.
- 2026년 2분기 자료를 등록하면 실제 등급과 자동으로 비교합니다.

**격자 화면**

- 등급 화면은 250m 격자 종합을 먼저 보여 줍니다. 격자를 누르면 항목별 값, 서울 기준, 판정, 미산출 사유가 표시됩니다.
- 일부 항목만 있는 격자는 종합을 내지 않고 항목만 보여 줍니다. 남은 항목이 어떤 값이어도 결과가 같은 격자만 '활성(일부 항목 확정)'으로 표시합니다.
- 빈 격자의 값은 추정하지 않습니다. 빈 격자는 대부분 외식업소가 없는 곳입니다.

**팝업 압력(참고 신호)**

- 등급·예측에 쓰지 않는 참고 지도입니다. 자료는 성동구의 성수동 팝업 주간 현황(엑셀)입니다.
- 구청 파일은 공개 저장소에 넣지 않습니다. `data/grades/popups.json`에는 팝업명·주소 없이 키값, 격자, 기간, 종류만 저장합니다.
- 주소는 `data/grades/address_grid.json`(공개 상가정보로 만든 도로명주소 → 250m 격자표)으로 격자에 배정합니다.
- 새 주차는 등급 화면의 분기 자료 등록에 엑셀을 그대로 올립니다. 묶음 재생성은 `scripts/popups/build_popups.py`로 합니다.
- 민간 팝업 플랫폼 자료는 운영사 동의 없이 자동 수집하지 않습니다.

**팝업 온라인 언급(참고 신호)**

- 네이버 블로그·뉴스 검색 API를 매일 04:30(KST) GitHub Actions로 조회합니다(`.github/workflows/popup-mentions-daily.yml`, `scripts/popups/collect_popup_mentions.py`). 블로그는 최신순 1,000건이 3~4일치라 주간 수집으로는 누락이 생깁니다.
- 제목에 '팝업'과 성수 지역어가 있는 글을 세고, 도로명주소가 있으면 250m 격자에 배정합니다. 팝업 수가 아니라 온라인 언급량이며 등급·예측에 쓰지 않습니다.
- `data/grades/popup_mentions.json`에는 주차별·격자별 건수만 저장합니다. 매일 바뀌므로 공개 자료 목록의 파일 확인값에는 넣지 않습니다.
- 매일의 커밋에는 `[daily-data]` 표시를 붙여 사이트를 다시 배포하지 않고, 월요일 커밋에서 사이트를 갱신합니다(`vercel.json`의 ignoreCommand).

등급은 참고 지표이며, 실제 임대료 부담이나 내몰림 여부를 판정하지 않습니다.

## 공개 자료

- 공개하는 자료는 다음과 같습니다.
  - 행정동·격자 경계(`data/observatory.json`)
  - 등급 계산용 집계값(`data/grades/`)
  - 입점 제한 지번표(`data/parcels.json`)
  - 배경지도 이미지
- 2026-11-03에 이전 단계의 원자료 수준 파일을 공개 범위에서 삭제했습니다. 대상은 월별 격자 관측값, 모형 입력값, 후보 변수 목록이며, 연구 작업 폴더에는 보존되어 있습니다.
- 파일 확인값은 `data/release-manifest.json`에 있습니다.
- 출처 표기: 배경지도 © OpenStreetMap contributors / 행정경계 SGIS 2023 / 공식 250m 격자.
- 입점 제한 지번
  - 2026-09-23 공식 계획 부록 550행 가운데 고유 지번 547개입니다. 입점 제한 구역 목록이며 지속가능발전구역 전체 경계와는 다릅니다.
  - 연무장길·방송대길 확대 제한은 2026-12-01 시행 예정입니다.

## 실행과 검증

Node.js 22 이상에서 실행합니다.

```sh
npm test
npm run build
npm run dev
```

- 개발 주소는 `http://127.0.0.1:4173`입니다.
- `tests/grades.test.mjs`는 브라우저 계산이 연구 코드(Python) 결과와 같은지 확인합니다.
  - 행정동·격자 전 분기 등급
  - 2026년 2분기 예측
  - 좌표 변환
  - 자료 등록 처리
- `tests/site-contract.test.mjs`는 공개 자료 범위, 지번 조회, 검토 기록 처리를 확인합니다.

## 이용 한계

- 지원 대상 선정이나 정책 도입 여부를 자동으로 판정하지 않습니다.
- 체크리스트를 모두 완료해도 정책 활용이 승인된 것은 아닙니다.
- 검토 기록과 등록 자료는 브라우저(`localStorage`)에만 저장되며 기기 간 동기화가 되지 않습니다.
- 신청인의 민감한 정보는 입력하지 마십시오.
- 실제 기관 운영에 쓰려면 무료(Hobby) 요금제 약관(개인·비상업 용도)에 맞는지 별도로 검토해야 합니다.
