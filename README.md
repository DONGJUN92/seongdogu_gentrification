# 성동구 상권 모니터링

성동구 전체 상권 관측지표 및 정책 검토 근거 조회용 독립 연구 웹앱. 성동구 공식 행정서비스와 별개.

- 공개 주소: https://seongsu-observatory.vercel.app
- 연구 기준: 2026-10-12 / 화면 확장: 2026-10-13
- 무료 Vercel Hobby 정적 배포 / 외부 패키지·서버 함수·DB·API 키 미사용

## 제공 범위

| 구분 | 제공 항목 |
|---|---|
| 공간 | 성동구 314개 격자·17개 행정동 / 성수동 교차 105개 격자 전환 |
| 시간 | 2022-01~2026-08, 56개월·17,584개 격자 기록 |
| D1 | 임대료·음식업 점포당 매출 4집단, 동반 상승 중 임대료 우위, 성장격차 |
| D2~D5 | 카드 구성 변화, 생활기반·교육 점포 비중 변화, 추정매출 변화, 보고 폐업 강도 |
| 관측 보조지표 | 기존 GIS 50항목의 값·단위·출처·자료충족 정보 |
| 확정 모형 IV | D1 29개, D4 35개 / 행정동·집계구별 전처리 전 원값 |
| 탐색 후보 IV | 분기 168개, 월별 165개 / 최종 채택 여부와 구분 |
| 정책 검토 | 성수동 공식 지번 547개 검색, 제도별 적용 단위·시점·필요 증빙 |
| 검토 기록 | 현재 브라우저 저장, Markdown/JSON 내려받기 |

`상권 현황 지도`에서 조회 범위·관측월·행정동·표시지표 선택. `IV·DV 전체 조회` 또는 `지표·변수 조회`에서 변수 목록, 행정동 4분면 비교, 원공간 입력 및 과거 평가사례 확인. 과거 예측은 보존된 성수동 평가사례에 한정되며 성동구 전체 예측 성능으로의 외삽 불가.

## 지표 정의 및 표시 원칙

- 주 DV 5개 유지. D1 동반 상승·임대료 우위는 Ⅰ집단 내부 세부 결과이며 독립 제6 주 DV로 변경하지 않음.
- 일반 상승률: `100 × (exp(로그변화) − 1)` (%).
- 일반 상승률 차이: 임대료 상승률−매출 상승률 (%p).
- 원연구 성장격차: `100 × (임대료 로그변화−매출 로그변화)` (로그포인트). 일반 상승률 차이와 단위 구분.
- D1의 0 이하: 감소 또는 정체. 한 축이라도 결측이면 4집단·격차·세부 결과 미산출.
- 월별 DV 표시월은 실현 종료월이며 예측 원점과 3개월 차이. 화면에 고정 비교기간 명시.
- 신용보증재단 수량: 집계구의 교차면적 배분 추정. 가격: 대표 교차 행정동의 분기 맥락. 250m 직접 임대차 실측으로의 해석 불가.
- 행정동 필터: 경계 교차 기준. 복수 행정동 교차 격자의 대표 행정동과 조회 행정동이 다를 수 있음. 행정동 간 격자 수 중복 합산 유의.
- 판정 민감도: 2026-03의 고정 교란 시나리오 결과. 실제 정확도·오분류 확률과 구분.
- 2026-08 종합 판정: 314개 전부 유보. 결측의 0 대체 및 이전 단계 이월 미적용.
- 탐색 후보의 표시: 연구에 보존된 후보 배열·입력표 범위. 최종 투입 IV·채택 효과·정책 타당성으로의 해석 불가.

## 자료 공개 및 보존

지역 집계값·원공간 모형 입력 참조값 공개. 개별 카드 거래·가맹점 식별자·사업체 주소·개인 심사 증빙·인증정보·사용자 메모 제외. 원모형·정답·보호 파일 20개 변경 없음. 원자료 저장소와 공개 앱 저장소 분리.

자료 해시: `data/release-manifest.json`. 초기 지도 자료와 별도로 관측월·모형·원점별 입력 파일을 필요한 시점에 조회하여 전송량 절감. 배경지도 © OpenStreetMap contributors / 행정경계 SGIS 2023 / 공식 250m 격자.

정책 지번은 2026-09-23 공식계획 부록 550행의 고유 지번 547개. 부분 입점 제한구역 목록이며 전체 법정 경계와 구분. 연무장길·방송대길 확대 제한은 2026-12-01 시행 예정 기재. 개별 적용요건·예외 동의 별도 확인 필요.

## 실행 및 검증

Node.js 22 이상:

```sh
npm test
npm run build
npm run dev
```

개발 주소 `http://127.0.0.1:4173`. `npm run preview`는 동일 주소에서 정적 빌드 결과 제공.

검증 범위: 기존 성수동 판정 보존, 성동구 전체 판정, 4집단 경계·결측, 일반 상승률 환산, 후보/채택 변수 구분, 제외 예측 보존, 검토 기록의 선택월·정책 보류 유지. 연구 작업 폴더의 독립 검증으로 17,584개 원기록, 관측 IV 879,200개 값, 확정 입력 1,049,036개 값 및 탐색 후보 배열 대조.

## 이용 한계

독립 미래 정답·실제 수령판본·개별 신청인 준거·정책 허용손실 기준 미확보. 관측자료 및 근거 검토용으로 한정. 정책 대상지역 지정·지원 적격성 자동판정 미제공. 체크리스트 완료와 정책 승인 상태 별개.

검토 기록은 `localStorage` 내부 저장. 기기 간 동기화·기관 전달 미제공. 민감한 신청인 정보 입력 금지. 무료 Hobby의 개인·비상업용 범위를 넘는 실제 기관 운영은 약관 적합성 별도 검토 필요. 유료 플랜 전환·체험·유료 리소스 생성 없음.
