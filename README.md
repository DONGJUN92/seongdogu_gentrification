# 성수 관측실

성수동 상권의 관측 변화, 자료의 범위, 정책 검토 근거를 연결하는 독립 연구용 웹앱입니다. 성동구 공식 서비스가 아닙니다.

## 주요 흐름

- **개요:** 검증된 관측 결과와 서로 다른 자료 시점을 확인합니다.
- **지역 살펴보기:** 105개 관측 격자의 월별 단계·자료충족·민감도를 조회합니다. 지도와 검색 목록을 함께 제공합니다.
- **정책 적용 범위:** 공식 계획의 547개 고유 지번을 검색하고, 현재/예정 시점과 원문 중복을 구분합니다.
- **연구 근거:** 5개 지표의 의미, 모형 비교, 공간검정의 한계와 공식 출처를 읽습니다.
- **검토 노트:** 관심 지역과 메모·근거 열람 기록을 브라우저에 저장하고 Markdown/JSON으로 내려받습니다.

## 실행

Node.js22 이상만 필요합니다. 외부 패키지, API 키, 데이터베이스, 서버 함수가 없습니다.

```sh
npm test
npm run build
npm run dev
```

개발 주소는 `http://127.0.0.1:4173`입니다. `npm run preview`는 빌드 결과를 같은 주소에서 제공합니다.

## 자료와 해석

연구 기준일은 **2026-10-12**, 종합지도 공통 최신 관측월은 **2026-03**, 카드 최신 관측월은 **2026-08**입니다. 이를 실시간 현황이나 현재 미래예측으로 읽지 않습니다. 자동 갱신 데이터가 아닙니다.

기존 D1–D5 정의·예측값은 변경하지 않았습니다. 원지도의 314개 성동구 표시셀 중 성수동에 걸치는105개에 대한 관측단계·자료충족 정보만 공개 패키지에 포함합니다. 원거래 금액, 가맹점 식별자, 개인·사업장 심사자료, 인증정보, 로컬 검토 노트는 공개 데이터에 포함하지 않습니다.

판정 민감도는2026-03의 비중·강도±0.5%p 및 로그±0.005 고정 교란 결과입니다. 정확도 또는 실제 오분류 확률이 아닙니다. 유보(P0)는 정상·안정이 아닙니다. S4는 복합신호 지속이며 정책 도입이나 피해 확정이 아닙니다.

정책 지번은2026-09-23 공식 지속가능발전계획 부록의550행(중복3개)에서 추출한547개 고유 지번입니다. 입점제한 부분구역의 지번목록이며 전체 지속가능발전구역의 정밀 법정 경계가 아닙니다. 확대 제한은 문서상2026-12-01 예정으로 표시합니다. 법정 요건·업종·층·가맹규모·예외 동의는 별도 확인해야 합니다.

기존 지도는 공간자료의 출처만 참고했으며 화면과 코드·업무 흐름은 새로 구성했습니다. 자료 해시는 `data/release-manifest.json`에 기록했습니다. 배경지도 © OpenStreetMap contributors, 행정경계 SGIS2023, 표시격자 공식250m. 공개문서의 권리는 각 발행기관에 있습니다.

## 배포와 비용

정적 `dist/` 폴더로 배포합니다. `vercel.json`은 무료 Hobby에서 사용할 정적 빌드를 지정합니다. 연결 계정의 Hobby 플랜은 배포 전 확인하며 유료 전환·Pro체험·유료 리소스 생성은 하지 않습니다. Hobby의 개인·비상업용 사용 범위를 넘어 실제 기관·상업 업무로 확장할 때는 무료 플랫폼의 약관 적합성을 다시 확인해야 합니다.

검토 노트는 `localStorage`에만 저장됩니다. 기기 간 동기화·서버 보관·기관 전달·사용자 인증을 제공하지 않습니다. 개인 식별정보나 민감한 신청인 증빙을 입력하지 마세요. 체크리스트 완료는 정책 승인 상태를 변경하지 않습니다.

## 검증

`npm test`는 원단계105개 수치, 최신시점105개 유보, 자료 누락, 공식 지번 중복·예정상태, 공개 데이터 제외필드, 로컬 노트 정규화와 정책승인 불변 조건을 검사합니다. 시각·키보드·모바일·내려받기 흐름은 실제 브라우저에서 별도로 확인합니다.

2026-10-12 로컬 검증: Node 테스트 10개와 정적 빌드를 통과했습니다. 실제 브라우저에서 3월/8월 전환, 민감도 미실시 표시, 지번 중복 검색·거리 필터, 노트 저장 후 새로고침, Markdown 내려받기와 선택월 보존, 체크리스트 6개 완료 후 정책 보류 유지를 확인했습니다. 모바일 390px 뷰포트의 지도와 메뉴 닫기를 확인했으며 문서 가로 넘침이 없었습니다. 이는 앱 기능 검증이며 연구 지표의 정책 타당성 검증을 의미하지 않습니다.

## 정책 사용 판정

현재 독립 미래 정답·실제 수령판본·신청인 준거·정책 손실 기준이 미확보입니다. 이 웹앱은 연구 근거 검토와 메모 작성을 돕습니다. 개인의 지원 적격성, 법적 규제 여부 또는 정책 도입을 자동 판정하지 않습니다.
